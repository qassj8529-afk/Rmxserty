# Portfolio Images

Place your project screenshots in this folder following the naming convention below:

## Required Images for Each Project:

### Project 1: Ristorante Milano
- `project1-desktop.png` - Desktop version screenshot (16:9 ratio recommended)
- `project1-mobile.png` - Mobile version screenshot (9:16 ratio recommended)

### Project 2: AutoCare Berlin
- `project2-desktop.png` - Desktop version screenshot
- `project2-mobile.png` - Mobile version screenshot

### Project 3: Bella Vista Salon
- `project3-desktop.png` - Desktop version screenshot
- `project3-mobile.png` - Mobile version screenshot

## Adding New Projects:

To add more projects to your portfolio:
1. Add your images here following the pattern: `project{number}-{view}.png`
2. Update the HTML in index.html to include the new project card
3. Replace {number} with your project number and {view} with "desktop" or "mobile"

## Image Specifications:
- **Format:** PNG (preferred) or JPG
- **Desktop:** 16:9 aspect ratio, 1200x675px recommended
- **Mobile:** 9:16 aspect ratio, 375x667px recommended
- **File Size:** Under 500KB each for fast loading

## Fallback System:
If images are missing, the website will automatically show professional placeholder boxes that say "Desktop View Loading..." and "Mobile View Loading..."
